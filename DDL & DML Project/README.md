# PostgreSQL DDL & DML – Duka Inventory Management

## 📌 Overview

This project demonstrates the fundamentals of **PostgreSQL Data Definition Language (DDL)** and **Data Manipulation Language (DML)** 
by building and managing a simple inventory database for a retail shop ("Duka").

## Objectives

- Create and manage database schemas and tables.
- Insert, retrieve, update, and delete data.
- Modify table structures using DDL commands.
- Understand basic database administration tasks.

## Technologies

- PostgreSQL
- SQL

## Concepts Covered

### DDL (Data Definition Language)
- `CREATE SCHEMA`
- `SET search_path`
- `CREATE TABLE`
- `ALTER TABLE`
  - Add Column
  - Rename Column
  - Modify Data Type
  - Drop Column
- `DROP TABLE`

### DML (Data Manipulation Language)
- `INSERT INTO`
- `SELECT`
- `UPDATE`
- `DELETE`

## Business Scenarios

This project demonstrates how to:

- Create a retail inventory database.
- Store product information.
- Update supplier details.
- Modify table structures as business requirements change.
- Remove obsolete products.
- Manage database objects efficiently.
